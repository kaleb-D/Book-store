# Kaleb Dereje — Portfolio

> A personal portfolio website built with **React** and **Tailwind CSS** showcasing projects, skills, and contact information.

---

## About this project

This portfolio is a fast, responsive, and accessible single-page application built using React and Tailwind CSS. It focuses on clean design, clear presentation of projects (including live demos and source links), and a smooth developer experience.

Designed for:

* Presenting projects (web, mobile, full-stack)
* Sharing a concise developer bio and tech stack
* Easy contact (email / LinkedIn / GitHub)

---

## Features

* Responsive layout for desktop, tablet, and mobile
* Hero section with short intro and CTA
* Projects gallery with descriptions, tech tags, and links
* Skills section with categorized tech stacks
* Contact section with mailto and social links
* Dark mode support 
* SEO-friendly meta tags
* Fast builds and small bundle sizes using code splitting

---

## Tech stack

* **Frontend:** React (Vite )
* **Styling:** Tailwind CSS
* **Routing:** React Router 
* **Forms / State:** React state 
* **Deployment:** Vercel

## Getting started (development)



1. Clone the repo:

```bash
git clone https://github.com/yourusername/your-portfolio.git
cd your-portfolio
```

2. Install dependencies:

```bash
npm install
```

3. Run the dev server:

```bash
npm run dev
# or npm start (if using CRA)
```

Open `http://localhost:5173`  in your browser.

---

## Build for production

```bash
npm run build
# serve the `dist` (Vite) or `build` (CRA) folder with a static server
```

## Project structure (example)

```

├─ public/                # static assets (images, resume.pdf)

```

## Accessibility & SEO

* Use semantic tags (`<header>`, `<main>`, `<section>`, `<footer>`).
* Add `alt` text for all images and `aria-*` attributes where needed.
* Include meta title/description and Open Graph tags in `index.html`.
